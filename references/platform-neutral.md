# 플랫폼 중립화 (선택 축 `platform`)

특정 에이전트로 만들어 쓰던 스킬을 공개하면 그 에이전트 전용 도구 이름이 문서에 그대로 남는다. 다른 에이전트 사용자에게는 존재하지 않는 이름이라, 개인정보 문제는 아니지만 **자기완결성 문제**다. 결합 축(`coupling`)이 "저자 컴퓨터에만 있는 것"을 본다면, 이 축은 "저자의 에이전트에만 있는 것"을 본다.

## 언제 고르나

기본(`all`)에 넣지 않은 선택 축이다. 특정 플랫폼용으로 만든 저장소(그 플랫폼의 플러그인·확장)에서는 그 이름이 정당한 내용이라, 상시 게이트에 넣으면 게이트가 꺼진다. **플랫폼 중립 공개를 목표로 정했을 때만** 이름으로 고른다.

```bash
python scripts/scan_traces.py <반출본> --axes all,platform
```

## 스캐너는 탐지만 한다

같은 도구 이름도 문맥에 따라 바꿀 말이 다르다. `javascript_tool`은 "값을 읽는다"는 문장에서는 "페이지에서 JS를 실행해 값을 읽는다"가 되고, 도구 묶음을 미리 불러오라는 문장에서는 문장 자체가 사라져야 한다(다른 에이전트에는 지연 로드 개념이 없다). 그래서 스캐너는 위치만 알려 주고, 바꾸는 말은 사람이 문맥을 읽고 정한다.

유형 B(정본/반출본 분리형)라면 정한 치환을 반출 스크립트에 박는다. 정본은 저자가 그 플랫폼으로 매일 쓰는 작업본이라 손대지 않고, 반출할 때마다 같은 치환이 다시 돌게 한다. 두 층으로 나누면 편하다.

- **줄 단위 단언 치환**: 문장 구조가 플랫폼에 묶인 줄(도구 묶음 로드, "○○ MCP 도구를 사용한다", 제품 고유 함정의 제목). 치환 횟수를 단언해, 정본 문장이 바뀌면 조용히 빗나가지 않고 멈추게 한다.
- **용어 일괄 치환**: 문맥을 한 번 훑어 도구 이름이 단순 지칭으로만 쓰인다고 확인한 뒤에만. 한국어라면 **조사를 다시 고른다**. `javascript_tool로`(툴로)를 `페이지 JS 실행로`로 두면 틀린다. 대체어 끝 글자의 받침으로 은/는·이/가·을/를·와/과·로/으로를 다시 정하는 함수를 거친다(ㄹ 받침은 `로`).

마지막에 반출본에 `--axes platform`을 돌려 0건(허용 제외)을 게이트로 건다(기본 축은 반출 절차가 따로 돌린다). 줄 단위 치환이 빗나간 것과 새로 들어온 플랫폼 표현이 여기서 함께 잡힌다.

## 대응표

| 플랫폼 표현 | 중립 서술 |
|---|---|
| `javascript_tool` | 페이지에서 JS 실행 |
| `read_page` | 접근성 트리(페이지 구조) 읽기 |
| `get_page_text` | 페이지 텍스트 추출 |
| `find` | 요소 찾기(설명으로 검색) |
| `computer` 좌표 클릭 | 좌표 클릭 |
| `computer` 스크린샷 | 화면 캡처 |
| `form_input` | 폼 값 설정 |
| `navigate` | 주소 이동 |
| `file_upload` | 파일 업로드 |
| `resize_window`, `list_connected_browsers` | 창 크기 조정, 연결된 브라우저 목록 조회 |
| `mcp__plugin_playwright_playwright__browser_click` | `browser_click`(Playwright MCP 도구 이름은 그대로 둔다) |
| `tabs_context`, `tabs_context_mcp` | 탭 목록 조회 |
| `tabs_create(_mcp)`, `tabs_close(_mcp)` | 새 탭 열기, 탭 닫기 |
| `browser_batch` | 여러 동작 일괄 실행 |
| `read_console_messages`, `read_network_requests` | 콘솔 로그·네트워크 요청 읽기 |
| `mcp__<서버>__<도구>` 묶음 로드 문장 | 필요한 기능 목록으로 바꾸거나 문장을 뺀다 |
| Claude in Chrome | 브라우저 제어 확장 |
| 앱 내장 브라우저 도구 | 에이전트의 내장 브라우저(있으면) |
| `claude -p` 같은 CLI 고정 호출 | 환경 변수로 바꿀 수 있게 하고 기본값으로만 남긴다 |

## 원칙

- **검증한 환경은 예시로 한 번 남긴다.** "브라우저 제어 확장(Claude in Chrome에서 검증)"처럼. 지우면 독자가 어디서 동작이 확인됐는지 모른다. 남긴 자리에는 `sanitize: allow <근거>`를 붙이거나 패턴 파일 `## 허용`에 넣는다.
- **다른 플랫폼에서도 된다고 단정하지 않는다.** 확인하지 않은 확장·에이전트가 같은 기능을 가진다고 쓰면 그것이 새 오류가 된다. 필요한 기능을 적고, 검증 환경을 적고, 그 사이는 독자에게 맡긴다.
- **설치 대상 안내는 허용이다.** README의 "Claude Code·Codex 등에 설치" 같은 문장은 종속이 아니라 배포처 안내다.
- **플랫폼 중립 도구는 남긴다.** Playwright·Chrome DevTools Protocol처럼 어느 에이전트에서나 쓰는 도구는 이름 그대로 둔다. Playwright MCP 서버의 `browser_navigate`·`browser_click` 같은 도구 이름도 MCP를 지원하는 에이전트라면 같으므로 스캐너가 보지 않는다. 바꾸는 것은 그것을 감싼 플랫폼 전용 래퍼의 접두어(`mcp__plugin_…__`)뿐이다.
- **CLI 고정 호출은 동작 변경이다.** 문서 치환과 달리 스크립트가 바뀌므로 그 스크립트의 시험도 함께 맞추고 돌린다.
